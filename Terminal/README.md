# BASE44 - SO15 Counter Terrorism Command Platform

A tactical web application for BASE44 unit.

## How to Run
1. Open `index.html` in your browser
2. Or deploy on Vercel / Netlify by dragging the folder

## Features
- SO15 Dark Tactical Theme
- Full Vehicle Roster (exact vehicles)
- Vehicle Booking System
- Deployment Log
- Intel Reports
- Documents Section
